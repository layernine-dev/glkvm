Connections

Open each device in its own frameless window.

Use a LAN or VPN address. Passwords are encrypted using your macOS keychain. Leave a saved password blank to keep it; changing the address clears it. Saving a password retries sign-in in the background. Start mode and window resolution apply when reopening a connection. Resolution scales video pixels, accounting for display density; sizes exceeding the screen or 6K limit fall back to automatic sizing.

Audio applies only to that connection's window and never changes your Mac's default devices. The focused setting is used while its window is focused, visible and not minimized; otherwise the background setting applies. All microphones and speakers on this Mac are listed, even while a connection is closed; listing never turns a microphone on. Microphones are only used when the device page turns on its own microphone. An unavailable device stays silent instead of falling back, and choices are kept when you change the address.

“When connecting” turns on the device page's own Sound or Microphone control the next time the connection connects or reconnects; saving does not change a running session, and later changes on the device page are kept. The microphone turns on only if it is enabled on the device (USB microphone) and selected here for the current window state. It is unavailable in Direct H.264 mode, and changing the address turns it off. Mute device audio in Controls still applies.

In move mode, drag the video to reposition the window. Press ⌘⇧M again to resume control. In view-only mode, you can always drag the video.

Device settings appear in the same window with ⌘⇧O. Press it again to hide the controls and window decoration. Visible settings are included when sharing that window. Camera access and downloads remain unavailable.

Keyboard

Send special keys and clipboard text to the remote computer.

Click a shortcut and press your preferred combination with Command, Control or Option. Escape cancels recording. Shortcuts apply to all connections while the video has keyboard focus. Insert defaults to ⌘´ (the key next to Backspace on a German Mac keyboard).

Paste sends plain text using the Toolbox text service, including line breaks. The Toolbox does not need to be open. This also handles paste shortcuts generated by text expanders such as Espanso. Images and rich formatting are not sent.
